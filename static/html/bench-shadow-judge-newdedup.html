Directional bias — how each judge errs vs Opus

FP = over-calls same_bug when Opus said different (lenient: would turn a MISS into a false HIT). FN = calls different when Opus said same (strict: would suppress a real hit). Every model leans lenient (FP > FN), so a cheap vote resolves borderline calls toward HIT, not Opus's stricter "different".
